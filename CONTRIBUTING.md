# Contributing

Please open an issue with a minimal reproduction, Python version, expected result, and observed result. Pull requests should include a test and keep runtime dependencies minimal. Do not include secrets, internal prompts, or proprietary data. This project is a research prototype, not a security boundary.

Unexpected real-world cases are especially welcome. Use the GitHub issue template and indicate what was directly observed versus inferred. A report does not need to include a fix. We may keep reports open as unverified until reproducible independent evidence is available. Do not submit personal data or sensitive production logs.
